Your computer. Your workspace.

Install Node 24 LTS, Python 3.12 (or uv), and FFmpeg with libass. Extract the source on a drive with enough space, then open PowerShell there:

npm ci --cache .cache/npm
npm run setup
npm run setup:faces
npm run build
npm start

Open localhost:5173. Face setup is optional. First transcription downloads a model; CPU processing can take several minutes. Jobs and exports stay in the project folder.

Automatic picks need review. This app provides reproducible editing presets; it does not discover live trends or predict views. YouTube availability can change. This download contains source code, not a bundled Windows executable.

Editing guide

  1. Start a project with a local recording or a supported public video link. Choose portrait for clips or landscape for longer edits.
  2. Review the suggested clips or open Video cutter to choose a section yourself. Edit the transcript, check the framing, and preview the finished clip.
  3. Export the MP4 or add it to the Posting Calendar. Your projects, transcript, and exports are saved in the OpenClip installation folder.

Posting guide

Use Automation to connect an account. In the Posting Calendar, preview the finished video and review its caption before sending it. YouTube supports scheduling through its connection.

With a TikTok developer app that has video upload access, OpenClip sends your selected portrait video to TikTok Inbox after you confirm. Copy your TikTok caption and hashtags from OpenClip and finish the post in TikTok.
