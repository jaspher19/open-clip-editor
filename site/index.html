Your computer. Your workspace.

Install Node 24 LTS, Python 3.12 (or uv), and FFmpeg with libass. Extract the source on a drive with enough space, then open PowerShell there:

npm ci --cache .cache/npm
npm run setup
npm run setup:faces
npm run build
npm start

Open localhost:5173. Face setup is optional. First transcription downloads a model; CPU processing can take several minutes. Jobs and exports stay in the project folder.

Automatic picks need review. This app provides reproducible editing presets; it does not discover live trends or predict views. YouTube availability can change. This download contains source code, not a bundled Windows executable.
